# Security Policy

## Supported versions

This project is early, so security fixes will land on the latest mainline version first.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Send a report to `espisteven5@gmail.com` with:

- a short summary
- reproduction steps or proof of concept
- impacted files or commands
- any suggested mitigation

I will review the report privately and respond as quickly as possible.
