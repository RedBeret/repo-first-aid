# Code of Conduct

This project aims to be practical, respectful, and welcoming.

## Expectations

- Be direct without being hostile.
- Focus feedback on the code, rules, and user impact.
- Assume good intent while still naming problems clearly.
- Avoid harassment, personal attacks, intimidation, or discriminatory behavior.

## Scope

These expectations apply in issues, pull requests, discussions, and other project spaces.

## Enforcement

If someone crosses the line, report it to `espisteven5@gmail.com`. I may remove content, lock threads, or block participation when needed to keep the project useful and safe.
